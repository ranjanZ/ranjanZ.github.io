Research Areas

Large Language Models

Advanced research in LLM fine-tuning, including SFT, PEFT, RLHF, PPO, and DPO. Developing efficient methods for domain adaptation and instruction tuning of foundation models.

Graph Machine Learning

Pioneering work in Graph Neural Networks for financial modeling, peer identification, and anomaly detection. Scaling GNN systems to process 400M+ multi-modal records.

Retrieval & RAG Systems

Building next-generation retrieval-augmented generation systems with hybrid retrieval (dense + BM25 + SPLADE), multi-level caching, and agentic reasoning capabilities.

Computer Vision

Deep learning approaches for video panoptic segmentation, image dehazing, de-raining, and anomaly detection. Morphological neural networks for robust visual understanding.

Quantitative Trading

Applying ML to financial markets through automated trading strategies, backtesting platforms, and real-time market analysis using agentic frameworks.

Reinforcement Learning

Developing RL algorithms for decision-making in complex environments, including multi-agent systems and reward optimization for LLM alignment.

Recent Projects

Trust or Abstention RAG System

Abstention-aware RAG system that answers only when evidence is sufficient. Hybrid retrieval (dense + BM25 + RRF) with confidence-based decision layer. Achieved MRR 0.68–0.99 on SQuAD v2 and custom MBZUAI dataset.

Legal Contract RAG System

Scalable agentic RAG system for legal contracts with autonomous multi-step reasoning. Two-phase metadata extraction, hybrid retrieval, and Llama 3.2 synthesis achieving 2–4s latency on CUAD/MAUD/ContractNLI.

Unified Retrieval Platform

Configuration-driven retrieval platform supporting CSV, S3, JSON with BM25, SPLADE, and dense retrieval. Features pluggable rerankers, multi-level caching, NER pipelines, and Graph RAG integration.

Multi-Platform Video Publishing

Automated pipeline using Gemini API for generating platform-optimized titles and descriptions. Integrated REST APIs for YouTube, Instagram, Facebook, and WhatsApp distribution.

NIFTY 500 Trading Platform

Automated backtesting and deployment platform for swing trading strategies. Real-time market scanning, technical analysis engine, and comprehensive audit logging.

Agentic News Analysis Framework

Real-time financial news analysis system categorizing M&A, investments, product launches. Dynamic tool-calling mechanism for immediate impact assessment.
